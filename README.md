## 2. 사전 준비 — 회원가입 및 키 발급

이 앱을 사용하려면 아래 서비스에 가입하고 키를 발급받아야 합니다.

### 2-1. KRX 정보데이터시스템 (필수)

> 2025년 12월 27일부터 KRX가 회원제로 전환되어 **로그인 없이는 주식 데이터 조회가 불가**합니다.

1. **https://data.krx.co.kr** 접속
2. 우측 상단 **회원가입** 클릭
   - 네이버/카카오 소셜 로그인으로 간편 가입 가능
3. 이메일 인증 완료
4. **ID와 비밀번호를 메모** → 앱 실행 시 입력하거나 환경변수로 설정

### 2-2. DART API (선택, 권장)

> DART 데이터가 있으면 재무제표 기반 정밀 필터링(ROE, ROA, 영업이익 등)이 가능합니다. 없어도 기본 스크리닝은 동작합니다.

1. **https://opendart.fss.or.kr/** 접속
2. 회원가입 (이메일 인증, 즉시 완료)
3. 로그인 → **마이페이지** → **인증키 신청**
4. 40자리 인증키 발급 (즉시)
5. **발급된 키를 메모** → 환경변수 `DART_API_KEY`에 설정

### 2-3. KRX Open API (선택)

> KRX 로그인이 장애일 때 대체 데이터 소스로 사용합니다. 평소에는 불필요합니다.

1. **https://openapi.krx.co.kr** 접속
2. 회원가입
3. **마이페이지** → **인증키 신청** (관리자 승인 필요, 수 시간 소요)
4. 승인 후 **서비스 이용 → 이용 신청**에서 아래 API 활성화:
   - 유가증권 일별매매정보
   - 코스닥 일별매매정보
   - 유가증권 종목기본정보
   - 코스닥 종목기본정보
   - ETF 일별매매정보
5. **발급된 키를 메모** → 환경변수 `KRX_OPENAPI_AUTH_KEY`에 설정

## 3. 설치 방법

### 요구사항

- **Python 3.10 이상** (3.11 권장)
- **Windows 10/11** (macOS/Linux에서도 동작 가능)
- **Git** (저장소 클론용)

### 단계별 설치

#### Step 1: 저장소 클론

```bash
git clone https://github.com/sadman1115/stock_screener.git
cd stock_screener
```

#### Step 2: 가상환경 생성

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
```

#### Step 3: 패키지 설치

```bash
pip install -r requirements.txt
```

> **참고**: LightGBM 설치 시 C++ 빌드 도구가 필요할 수 있습니다.
> Windows에서 오류가 나면 `pip install lightgbm` 으로 별도 설치하세요.

#### Step 4: 환경변수 파일 생성

```bash
# .env.example을 복사하여 .env 파일 생성
cp .env.example .env
```

`.env` 파일을 텍스트 편집기로 열고, [2. 사전 준비](#2-사전-준비--회원가입-및-키-발급)에서 발급받은 키를 입력합니다:

```ini
KRX_MBR_ID=내KRX아이디
KRX_PW=내KRX비밀번호
DART_API_KEY=발급받은40자리키
KRX_OPENAPI_AUTH_KEY=발급받은40자리키
```

## 4. 환경변수 설정

`.env` 파일 대신 직접 환경변수를 설정할 수도 있습니다:

```bash
# Windows PowerShell
$env:KRX_MBR_ID = "내아이디"
$env:KRX_PW = "내비밀번호"
$env:DART_API_KEY = "40자리키"

# Windows CMD
set KRX_MBR_ID=내아이디
set KRX_PW=내비밀번호
set DART_API_KEY=40자리키

# macOS / Linux
export KRX_MBR_ID="내아이디"
export KRX_PW="내비밀번호"
export DART_API_KEY="40자리키"
```

| 환경변수 | 필수 여부 | 설명 |
|----------|-----------|------|
| `KRX_MBR_ID` | **필수** | data.krx.co.kr 회원 ID |
| `KRX_PW` | **필수** | data.krx.co.kr 비밀번호 |
| `DART_API_KEY` | 선택 | DART 재무제표 API 키 |
| `KRX_OPENAPI_AUTH_KEY` | 선택 | KRX Open API 인증키 |

> **주의**: `.env` 파일은 `.gitignore`에 포함되어 있어 git에 커밋되지 않습니다.
> API 키나 비밀번호를 절대 코드에 직접 입력하지 마세요.

## 6. 페이지별 사용법

### 📊 Page 1: 데이터 수집

전종목 시세/재무 데이터를 KRX에서 다운로드합니다. **모든 분석의 시작점**입니다.

#### 사용 순서

1. **기준일 설정**: 분석하고 싶은 날짜 입력 (기본값: 최근 거래일)
2. **KRX 로그인 설정**: 펼쳐서 ID/비밀번호 입력 (환경변수로 설정했으면 자동 입력)
3. **DART API 키**: 발급받은 키 입력 (선택)
4. **"일별 데이터 수집"** 버튼 클릭
5. 수집 완료 후 **"DART 재무 수집"** 버튼 클릭 (선택)

#### 수집되는 데이터

| 항목 | 설명 | 소요 시간 |
|------|------|-----------|
| 전종목 티커 | KOSPI/KOSDAQ ~2,800종목 | ~10초 |
| 당일 OHLCV | 시가/고가/저가/종가/거래량 | ~15초 |
| 펀더멘탈 | PBR/PER/BPS/EPS/배당수익률 | ~30초 |
| 시가총액 | 시총/상장주식수 | ~10초 |
| 업종분류 | 종목별 업종 | ~10초 |
| 20일 OHLCV | 최근 20거래일 시세 (모멘텀 계산용) | ~2분 |
| DART 재무 | 분기 손익계산서/재무상태표 | ~5분 |

#### 주의사항

- **주말/공휴일**에는 KRX API가 느릴 수 있습니다. 평일 장 마감 후(15:30~) 수집을 권장합니다
- **캐시**: 한번 수집한 데이터는 자동 캐시됩니다. 같은 날짜를 다시 수집하면 즉시 완료
- **캐시 초기화**: 데이터를 갱신하려면 "일별 캐시 초기화" 클릭 후 재수집
- **KRX Open API 우선 모드**: KRX 로그인이 안 될 때 체크박스를 켜면 Open API로 대체 수집

### 📊 Page 4: AI 수익률검사 (급등주 백테스트)

AI 급등 예측 모델의 과거 성과를 검증합니다.

#### 사용 순서

1. **"AI 모델 학습"** 버튼 클릭 (최초 1회, ~5분 소요)

3. **보유기간 선택**: 3/4/6/8/10/12주
4. 결과 확인:
   - **요약 테이블**: 평균수익률, 승률, 샤프비율, 최대낙폭
   - **누적수익률 차트**: AI 포트폴리오 vs KODEX200 vs KOSDAQ150
   - **주간수익률 분포**: 히스토그램
5. 기간별(2년/1년/6개월/3개월/1개월) 세부 지표 확인

#### 주요 지표

| 지표 | 설명 |
|------|------|
| 평균 주간수익률 | 매주 포트폴리오의 평균 수익률 |
| 승률 | 양(+)의 수익을 낸 주의 비율 |
| 샤프비율 | 위험 대비 초과수익 (1.0 이상이면 양호) |
| 최대낙폭(MDD) | 최고점 대비 최대 하락폭 |

## 7. 자주 묻는 질문 (FAQ)

### Q: KRX 로그인이 안 됩니다

**A**:
- data.krx.co.kr에서 직접 로그인이 되는지 확인하세요
- 소셜 로그인(네이버/카카오)으로 가입한 경우, 별도의 ID/비밀번호 설정이 필요할 수 있습니다
- "KRX Open API 우선 사용" 체크박스를 켜면 로그인 없이 Open API로 대체 수집이 가능합니다 (단, 당일 데이터는 익영업일에 갱신)

### Q: 주말에 데이터 수집이 안 됩니다

**A**: KRX API는 주말/공휴일에 응답이 느리거나 빈 데이터를 반환합니다. **가장 최근 거래일** 날짜로 수집하세요. 앱이 자동으로 최근 거래일을 감지합니다.

### Q: DART 없이도 사용할 수 있나요?

**A**: 네. DART 데이터 없이도 기본 스크리닝과 AI 모델은 정상 동작합니다. 다만 재무제표 기반 정밀 필터(ROE, ROA, 영업이익률 등)가 비활성화되어 결과의 정밀도가 낮아질 수 있습니다.

### Q: AI 모델 학습에 시간이 오래 걸립니다

**A**:
- 최초 학습: ~5분 소요 (71개 피처 × ~2,800종목 × 2년)
- 한번 학습하면 캐시에 저장되어 재실행 시 즉시 로드
- 강화학습 일괄진화(10세대): ~30분

### Q: 캐시를 모두 삭제하고 싶습니다

**A**: `low_pbr_screener/cache/` 폴더를 삭제하면 됩니다. 또는 Page 1에서 "전체 초기화" 버튼을 사용하세요.

### Q: 이 앱의 예측을 실제 투자에 사용해도 되나요?

**A**: **투자 참고용**으로만 사용하세요. AI 모델의 과거 성과가 미래 수익을 보장하지 않습니다. 모든 투자 판단과 책임은 본인에게 있습니다.
